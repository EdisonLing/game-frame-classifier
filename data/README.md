# Data directory

Official layout: **[docs/data-layout.md](../docs/data-layout.md)**.

## Collecting clips (drag and drop)

```text
data/raw/<Game>/<source>/*.mp4
```

1. Open the game folder (`Valorant`, `League_of_Legends`, `CS2`, `Minecraft`, `Overwatch_2`, `Marvel_Rivals`).
2. Create a folder for yourself or a friend (e.g. `edison`, `friend_alex`).
3. Drop clips in — **no renaming**.

A later script can copy/normalize paths for tooling; collection stays game-first.
